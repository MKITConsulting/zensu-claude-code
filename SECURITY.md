# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | Yes       |

## Reporting a Vulnerability

If you discover a security vulnerability in this plugin, please report it responsibly.

**Email:** [security@zensu.dev](mailto:security@zensu.dev)

**Response SLA:** We will acknowledge your report within 72 hours and provide an initial assessment within 7 business days.

**Scope:**
- Plugin code (skills, agent definitions, hooks)
- Hook behavior and shell command execution
- MCP server connection configuration
- Credential handling and data exposure risks

**Out of scope:**
- The Zensu SaaS platform (see [zensu.dev](https://zensu.dev) for its own disclosure policy)
- Third-party dependencies not maintained by Zensu

## Disclosure Policy

We follow coordinated disclosure with a 90-day window:

1. Reporter submits vulnerability details via email
2. We acknowledge within 72 hours
3. We investigate and develop a fix
4. We coordinate a disclosure date with the reporter (within 90 days)
5. Fix is released and advisory published

If we are unable to resolve the issue within 90 days, we will work with the reporter to agree on an extended timeline or coordinate public disclosure.

## Safe Harbor

We consider security research conducted in good faith to be authorized. We will not pursue legal action against researchers who:

- Act in good faith to avoid privacy violations, data destruction, and service disruption
- Only interact with accounts they own or with explicit permission
- Report vulnerabilities promptly and do not exploit them beyond what is necessary to demonstrate the issue
